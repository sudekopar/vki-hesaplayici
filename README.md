⚖️ Vücut Kitle İndeksi (VKİ) Hesaplayıcı
Bu proje, kullanıcının boy ve kilo bilgilerini alarak Vücut Kitle İndeksini (BMI) hesaplayan ve sonuçlara göre sağlık durumuna dair geri bildirim veren basit ama etkili bir web uygulamasıdır.
🚀 Özellikler
Dinamik Hesaplama: JavaScript kullanılarak anlık VKİ hesaplaması yapılır.
Görsel Geri Bildirim: Sonuçlar (Zayıf, Normal, Kilolu, Obez) farklı renk kategorileriyle kullanıcıya sunulur.
Responsive Tasarım: Modern CSS teknikleri ile hem mobil hem masaüstü uyumlu arayüz.
Hata Yönetimi: Geçersiz veya boş girişler için kullanıcıyı uyaran kontrol mekanizması.
🧮 Kullanılan Matematiksel Formül
Proje kapsamında kullanılan temel mühendislik formülü şöyledir:VKİ = Kilo (kg) / (Boy (m) * Boy (m))
🛠️ Kullanılan Teknolojiler
HTML5: Sayfa yapısı ve form elemanları.
CSS3: Modern, temiz ve kullanıcı dostu arayüz tasarımı.
JavaScript (ES6+): Hesaplama mantığı ve DOM manipülasyonu.
